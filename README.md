# 📐 삼각형의 합동 탐정단 (SSS · SAS · ASA 마스터 트레이너)

> **중학교 1학년 수학 2학기 「도형의 성질 - 삼각형의 작도와 합동」** 단원 연계  
> 학생들이 **SSS · SAS · ASA** 조건만 체계적으로 조사하여 두 삼각형의 합동 여부를 판별하도록 훈련하는 웹 애플리케이션입니다.

---

## 🌟 주요 기능 및 교육적 설계

### 1. 🔍 단계별 조건 조사 탐정 모드 (Step-by-Step Detective)
학생들이 감으로 찍지 않고, 체계적인 4단계 사고 루틴을 체화할 수 있도록 설계되었습니다.
1. **1단계 [단서 세기]**: 문제에 표시된 변($S$) 몇 쌍, 각($A$) 몇 쌍인지 개수 파악
2. **2단계 [위치 관계 조사]**:
   - 변 2개 + 각 1개: 두 변 사이의 **"끼인각"**인지 확인 (SSA 함정 걸러내기)
   - 변 1개 + 각 2개: 알려진 변의 **"양 끝 각"**인지 확인 (또는 $180^\circ$ 계산을 통해 양 끝 각 환산)
3. **3단계 [최종 판정]**: SSS, SAS, ASA, 또는 합동 조건 불충분(합동 아님) 선택
4. **4단계 [대응점 순서 맞추기]**: $\triangle\text{ABC} \equiv \triangle[\text{ }][\text{ }][\text{ }]$ 형식으로 서술형 필수 대비

### 2. ⚡ 실전 스피드 판별 퀴즈 (Speed Quiz)
- **Lv 1 (기본형)**: 나란히 놓인 삼각형 조건 식별
- **Lv 2 (회전/대칭형)**: 회전 및 뒤집힌 삼각형에서 기호(/, //, ///) 매칭 훈련
- **Lv 3 (시험 단골 함정)**: SSA 함정, AAA 함정, $180^\circ$ 계산 ASA 응용
- **Lv 4 (무한 챌린지)**: 무작위 생성되는 실전 챌린지
- 콤보, 점수, 효과음, 콘페티 축하 애니메이션 지원

### 3. 🔬 SSA 함정 시뮬레이터 & 인터랙티브 실험실 (Interactive Lab)
- **컴퍼스 시뮬레이터**: 왜 SSA(끼인각이 아닌 각)는 합동이 성립하지 않는지 컴퍼스 회전을 통해 둔각/예각 2가지 삼각형이 생성되는 원리를 슬라이더로 직접 시각화
- **합동 조건 조립기 (Congruence Builder)**: 변과 각의 스위치를 켜고 끄며 합동 조건이 완성되는 순간 "합동 잠금(Lock)" 발동

### 4. 🪟 실시간 포개어보기 시뮬레이션 (Superpose Modal)
- 오른쪽 삼각형이 부드럽게 이동·회전하여 왼쪽 삼각형 위로 포개어지는 애니메이션
- 합동이면 완벽 일치, 합동이 아니면 불일치 영역을 시각적으로 확인

## 🏫 학급 플랫폼 / LMS 연동 (100점 만점 차등 배점)

바이브코딩 및 학교 홈페이지 iframe 연동 규격(`postMessage`)을 완벽하게 지원합니다.  
단순 100점 완료가 아닌, **학생의 행동(1차 정답률, 함정 간파 능력, 대응점 일치율, 시뮬레이션 탐구 태도)**을 정밀 분석하여 100점 만점으로 차등 채점합니다.

### 차등 배점 기준표 (100점 만점)
| 평가 영역 | 배점 | 평가 기준 |
| :--- | :---: | :--- |
| **기본 조건 판별력** | **55점** | SSS, SAS, ASA 1차 시도 정답률 (오답 시 소폭 감점) |
| **함정 극복 능력** | **25점** | SSA 끼인각 아님, AAA 크기 다름, $180^\circ$ 계산 ASA 방어력 |
| **서술형 대응점 정확도** | **15점** | $\triangle\text{ABC} \equiv \triangle\text{DEF}$ 꼭짓점 순서 1차 일치도 |
| **탐구 태도 보너스** | **5점** | 힌트 비의존, 포개어보기 시뮬레이션 활용, 연속 정답(스트릭) |

### 전송 코드 프로토콜
```javascript
window.parent.postMessage({
  type: 'MATH_SCORE_SUBMIT',
  score: 88, // 100점 만점 중 학생 행동에 따른 차등 산출 점수
  details: '[중1 삼각형합동] 88점(A등급) | 1차정답률: 85% | 함정방어: 25/25점 | 대응점일치: 12/15점'
}, '*');
```

## 🛠️ 기술 스택 및 로컬 실행 방법

- **프레임워크**: React 19 + Vite 8
- **스타일링**: Tailwind CSS v4
- **아이콘 & 애니메이션**: Lucide React, Canvas Confetti
- **오디오**: Web Audio API (외부 에셋 다운로드 없는 자체 신디사이저)

```bash
# 패키지 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```
